# Visual design
Evaluate hierarchy, typography, spacing, alignment, density, contrast, semantic color, affordances, component consistency, states, feedback, brand fidelity, content and responsive behavior. Inspect existing tokens first. Establish hierarchy before decoration; test realistic content, long labels and edge states. Novelty is not quality. Use visual trends only when they improve clarity and fit.


## Visual asset continuity
For existing screens, inventory icons, images, illustrations, logos, and media before redesign. Preserve each correct asset in its original component and data instance; adapt or replace only with a clear semantic, quality, accessibility, or approved brand rationale. Check shared versus instance-specific assets, responsive crops, focal points, and accessible text. See `visual_asset_preservation.md` for the full protocol.
