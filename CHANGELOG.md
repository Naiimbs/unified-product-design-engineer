# Changelog

## 1.0.0
- Initial full multi-platform adaptive skill package.
- Includes master skill, 15 references, 9 workflows and 10 templates.

## 1.1.0
- Added Visual Context and Asset Preservation protocol to the master skill.
- Updated redesign workflow to inventory assets and preserve component-to-asset bindings.
- Added `references/visual_asset_preservation.md` with asset decision rules, repeated-instance guidance, accessibility checks, and verification criteria.

## 1.2.0
- Added Visual Intelligence mode for structured screen, component, state, and asset interpretation with confidence labels.
- Added Validation Lab workflow with three minimum test cases: existing UI audit, asset-preserving redesign, and new-flow design.
- Added validation evidence levels, a 0–4 scoring rubric, weighted scoring guidance, and critical-failure overrides.
- Added visual inventory template for capture context, component/asset mapping, interactions, responsive/localization observations, and accessibility cues.
- Refactored the master skill to remove duplicated visual-asset sections and duplicate index entries.
